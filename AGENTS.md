# AGENTS.md — Boss Rush

Instructions for coding agents (Claude Code, Gemini CLI, OpenCode and others) working in this repository.

## What this project is

Boss Rush is a pixel-art iPhone lock screen where each real deadline is a boss: the nearest one stands in front of the hero and transforms as its date nears, and the rest wait in line. The picture depends only on the plan and the time. The web app plans the deadlines, previews any moment and exports the wallpaper at the phone's exact size. See `README.md`.

## Commands

Package manager is Bun (v1.4.4). Python tools run through uv.

```sh
bun install
bun run dev              # web app (Vite); add --host to open it from a phone on the same Wi-Fi
bun run test             # Vitest in every package
bun run lint             # ESLint (includes determinism rules for core/render)
bun run typecheck        # tsc --noEmit in every package
bun run build            # production build of packages/web
bun run check            # lint + typecheck + test + build: run it before every commit

bun run --filter @boss-rush/<core|render|web|tools> test        # one package
BR_STRICT_ART=1 bun run check                                    # plus the strict art and font checks
UPDATE_GOLDEN=1 bun run --filter @boss-rush/render test          # regenerate golden images on purpose

bun run --filter @boss-rush/tools art:import                     # art/src -> art/export (atlas, sprites)
bun run --filter @boss-rush/tools art:lint
bun run --filter @boss-rush/tools <hero|font|ground>:import      # regenerate render/src/art/*.ts
```

## Repo map

| Path | Holds | Notes |
| --- | --- | --- |
| `packages/core` | Plan schema, `derive()` (plan + time to scene), picture-pack list, layout profiles, palette, sample plan | Pure TS. No DOM, no clock, no network. |
| `packages/render` | Scene + profile + atlas to pixels to PNG; 5 x 7 font | Pure and deterministic. Golden PNGs in `test/golden/`. |
| `packages/web` | Vite + Preact app: Preview, Planner, Export tabs | |
| `packages/tools` | Art import, atlas packer, palette lint; hero, font and ground converters | Bun scripts; Python via uv for font and ground. |
| `art/src` | The original pictures: `boss_<id>/{light,dark,final[,monster]}.png`, hero, font sheet, backdrop | Input to the converters. Real 8-bit PNG on a flat bright green background. |
| `art/export` | Atlas, sprites and import settings | Generated by `art:import`; never edit by hand. |
| `art/ref` | Box-mannequin pose references (Python, rendered to SVG and PNG) | Attached to image-model prompts to control camera angles. |
| `docs/img` | Pictures used by `README.md` | |

## Hard rules

- **Deterministic rendering.** Same plan + timestamp + profile gives a byte-identical PNG. No `Date.now()`, `new Date()` without an argument, `Math.random()`, `fetch` or DOM inside `core` or `render`; `now` is always a parameter. ESLint enforces most of this.
- **Colours only from `packages/core/src/palette.ts`** (which includes the generated `palette.bosses.ts`). **Sizes and positions only from `packages/core/src/profiles.ts`.** No magic numbers for layout anywhere else.
- **Scaling is whole-number nearest-neighbour**, through `fit()` in `profiles.ts`. Never smooth, never fractional.
- **The picture depends only on plan + time.** No health, damage or done state; do not add one.
- **Schema changes** bump `version` in the plan and add a migration plus a test.
- **Generated files are regenerated, never hand-edited:** `art/export/**`, `packages/core/src/palette.bosses.ts`, `packages/core/src/palette.ground.ts`, `packages/render/src/art/{hero,font,ground}.ts`. Change the source picture or the converter and re-run it.
- **Golden images change only on purpose.** Regenerate them deliberately and look at the new pictures before committing.
- **A boss whose short name is exactly `???` keeps its date secret:** its name and countdown show `???` and its timer stays full, everywhere (lock screen, preview, notifications).
- **Original characters only.** Borrow the era's pixel-art style, never another game's characters, names or sprites.
- **Pixel art:** no gradients, no anti-aliasing, no semi-transparent pixels.
- **iOS behaviour** is stated only when tested on a device; anything untested is labelled as untested.
